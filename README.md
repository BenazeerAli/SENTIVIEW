# SENTIVIEW
Movie Review Sentiment Analysis and Recommendation Systems
In this project, the domain of Movie Review Sentiment Analysis and Recommendation Systems was explored using distributed data processing on a Hadoop framework. The implementation of this was done through a Google Cloud Dataproc. The dataset for this project was collected by integrating a large-scale and intensive professional critic review and user review data from Rotten Tomatoes. 
The project pipeline included performing  preprocessing, sentiment computation, and similarity-based recommendations in a distributed PySpark environment. A hybrid architecture that uses Google Colab as the frontend and Google Cloud Platform (GCP) as the backend was employed. Hadoop functionality is provided via Dataproc, a managed service for running Spark and Hadoop clusters. The dataset ingestion is followed by text preprocessing, then sentiment analysis is used for movie recommendation generation, finally automated cluster lifecycle management is used to optimize the usage of the cloud resource.
